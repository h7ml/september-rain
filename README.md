# 蒹葭互动故事

一款关于青春、等待、遗憾与成长的中文互动叙事游戏。

玩家从看台上的白裙子开始，在雨天、银杏路、空教室、末班公交、海边书店和多年后的清晨之间做出选择。故事的终点也许不会改变，但每一次选择都会改变你如何记住这段经历，并把遗憾变成继续向前的力量。

## 游戏功能

- 章节式互动剧情，每章提供不同回应。
- 故事地图：按地点和记忆节点选择章节。
- 选关与历史存档：可回到已读章节，刷新页面后自动恢复进度。
- 收藏故事卡片，并查看历史结果。
- 分享、下载和复制结果卡片，内容带有 `jiangjia.story` 来源标识。
- 原文阅读与复制，复制内容保留原文版权声明。
- 场景化视觉效果：雨、雪、海边、夜晚、春日等主题拥有对应背景、动效和光标。
- 新故事生成：输入故事主题和角色设定，通过 Vercel AI Gateway 生成可游玩的分支剧情。
- 响应式单屏体验：适配桌面端和移动端，小屏内容可自然滚动，不强制裁切。
- 终章收束：故事到达尾声后不会继续出现可玩的选择，并会给出温暖、向上的总结。

## 技术栈

- Next.js 16 App Router
- React 19
- TypeScript

- Vercel AI SDK 与 AI Gateway

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 [http://localhost:3000](http://localhost:3000) 开始游戏。

生产构建：

```bash
pnpm build
pnpm start
```

## AI 新故事

点击游戏顶部的“新故事”，输入主题和角色设定后提交。请求会发送到：

```text
POST /api/generate-story
```

模型调用只发生在服务端路由中，生成结果会转换成章节、地点、正文、引文和选择按钮，随后直接载入游戏。

## 数据保存

当前版本使用浏览器本地存储保存以下内容：

- 当前章节和游戏是否开始
- 生成后的章节内容
- 收藏章节
- 历史存档

清理浏览器站点数据会清除本地进度。不同浏览器或设备之间不会自动同步。

## 原文与版权

项目保留用户提供的原文故事，并提供原文阅读与复制入口。原文展示、分享和复制内容会带有版权声明：原文故事版权归原作者所有；项目仅提供互动编排与阅读体验。

## 设计原则

游戏以克制、留白和场景氛围为主，不把遗憾处理成单纯的失败。所有分支最终都指向一次自我理解：过去无法重写，但玩家可以带着记忆继续向光而行。
